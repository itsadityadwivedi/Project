#A🛍️ Food Delivery Web Application using Spring Boot

📌 Project Overview
This project is a comprehensive food delivery web application developed using HTML, CSS, Java, Spring Boot, JSP, and Hibernate. It encompasses both Admin and User modules, facilitating seamless product management and user interactions. The application supports full CRUD operations, ensuring efficient handling of products, categories, and user data. Designed with a beginner-friendly approach, it serves as an excellent foundation for understanding web development with Spring Boot.

🔐 Admin and User Panels
Admin Panel: Accessible via http://localhost:8080/admin, the admin interface allows for managing products, categories, and customer information. Admins can add, update, or delete products, oversee customer details, and monitor sales analytics.

User Panel: Users can browse products, register, log in, and manage their profiles. The user interface provides a smooth shopping experience, including viewing product details and managing the shopping cart.

🚀 Features
✅ Spring MVC, JSP, Hibernate Integration
✅ Comprehensive Admin and User Modules
✅ Full CRUD Functionality
✅ User Authentication and Authorization
✅ Responsive Design for Enhanced User Experience

🛠️ How to Run the Project

Prerequisites:
Eclipse IDE with Spring Tools Suite
MySQL Database (e.g., via XAMPP)
Java Development Kit (JDK)

Setup:
Clone the repository and import it into Eclipse.
Create a MySQL database named springproject.
Import the springproject.sql file to set up the necessary tables.

Run the Application:
Right-click on the project in Eclipse.
Select Run As > Spring Boot App.
Open http://localhost:8080/ in your web browser.

📁 Project Structure

📦 Maven Wrapper Files
The project includes mvnw and mvnw.cmd files, which are part of the Maven Wrapper. These files allow you to run Maven commands without requiring a local Maven installation, ensuring consistency across different development environments. It's recommended to include these files in your GitHub repository.
